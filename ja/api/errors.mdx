# エラー {#errors}

The Prompting Company の JSON エンドポイントは、成功時・失敗時ともに `ApiResult<T>` エンベロープを返します。

## 結果の構造 {#result-shape}

```ts
type ApiSuccess<T> = {
  ok: true;
  data: T;
};

type ApiError = {
  ok: false;
  code: ApiErrorCode;
  message: string;
  details?: unknown;
};

type ApiResult<T> = ApiSuccess<T> | ApiError;
```

`data` を読み取る前に、`ok` を確認してください。

```ts
const result = await response.json();

if (!result.ok) {
  console.error(result.code, result.message, result.details);
  return;
}

console.log(result.data);
```

## 主なメッセージ {#common-messages}

| メッセージ                     | 意味                                       |
| ------------------------- | ---------------------------------------- |
| `authentication required` | 有効なセッション、ベアラートークン、または API キーが見つかりませんでした。 |
| `invalid api key`         | `x-api-key` の値を検証できませんでした。               |
| `public_api_only`         | API キーで内部ルートを呼び出そうとしました。                 |
| `auth_method_not_allowed` | このエンドポイントは、使用した種類の認証情報に対応していません。         |
| `insufficient_scope`      | ベアラートークンまたは API キーに必要なスコープが付与されていません。    |
| `rate_limited`            | 現在のレート制限バケットの上限を超えました。                   |

## リクエストID {#request-ids}

すべてのラッパーレスポンスには、次の内容が含まれます。

```text
x-request-id: 6efaa25e-3ef6-4a34-91c1-7ff3e0fd4cc8
```

独自の `x-request-id` を送信することもできます。その場合、値には英字、数字、`_`、`.`、`-`、`:` のみを使用し、長さは 128 文字以内にしてください。安全でない値が指定された場合、TPC は新しい ID に置き換えます。

失敗したリクエストの調査をサポートに依頼する際は、リクエスト ID をお伝えください。
