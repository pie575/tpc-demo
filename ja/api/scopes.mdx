# スコープ {#scopes}

スコープは、API キーまたは OAuth bearer トークンで実行できる操作を定義します。セッション経由の呼び出しではスコープのチェックは行われません。ダッシュボードでは、スコープの代わりにルート単位で組織とプロダクトの認可を行っているためです。

ワークフローの実行に必要な最小限のスコープのみを付与してください。

## カタログ {#catalog}

| スコープ                | 説明                                       |
| ------------------- | ---------------------------------------- |
| `content:read`      | サイトページ、Markdown コンテンツ、llms.txt ファイルの読み取り |
| `content:write`     | サイトページとコンテンツの作成、更新、削除                    |
| `prompts:read`      | プロンプト、トピック、プロンプト候補、プロンプト分析結果の読み取り        |
| `prompts:write`     | プロンプトの作成、更新、アーカイブ、およびプロンプト候補の生成、編集、レビュー  |
| `simulations:read`  | エージェントシミュレーションのタスク、実行、環境、アナリティクスの読み取り    |
| `simulations:write` | シミュレーション実行の作成とトリガー                       |
| `logs:read`         | AI トラフィックログとリクエスト単位の監査イベントの読み取り          |
| `analytics:read`    | ランキング、言及、ソース、SOV などのアナリティクス集計の読み取り       |
| `analytics:write`   | アナリティクスへのイベントの書き込み                       |
| `products:read`     | プロダクトのメタデータと競合データの読み取り                   |
| `products:write`    | プロダクト設定と競合リストの更新                         |

<Note>
  このカタログは `apps/client/src/lib/api/scopes.ts` の内容を転記したものです。スコープの追加、名前変更、
  削除を行う際は、必ず両方を更新してください。
</Note>

## 最小スコープの例 {#minimum-scope-examples}

| タスク                        | 最小スコープ                                  |
| -------------------------- | --------------------------------------- |
| 読み取り専用のダッシュボード連携           | `content:read`                          |
| ページを書き込むコンテンツ同期パイプライン      | `content:read`, `content:write`         |
| アナリティクスのエクスポートジョブ          | `analytics:read`                        |
| プロンプトのレポート作成ジョブ            | `prompts:read`                          |
| シミュレーションランナー               | `simulations:read`, `simulations:write` |
| サポート用またはコンプライアンス監査用のエクスポート | `logs:read`                             |

## 拒否されたリクエスト {#denied-requests}

トークン方式の呼び出し元に必要なスコープが付与されていない場合、TPC は `403` を返します。

```json
{
  "ok": false,
  "code": "FORBIDDEN",
  "message": "insufficient_scope",
  "details": {
    "requiredScopes": ["content:write"],
    "missingScopes": ["content:write"]
  }
}
```

新しいキーを作成するか、既存のインテグレーションキーをローテーションしてください。操作は次の場所から行えます。

```text
https://app.promptingco.com/{orgSlug}/settings/api-keys
```

ダッシュボードやレポート作成にのみ使用するキーには、書き込みスコープを追加しないでください。
