# TypeScript SDK {#the-typescript-sdk}

The Prompting Company プラットフォームからエージェント向け Markdown ドキュメントのデータにアクセスするための公式 TypeScript SDK です。完全な型安全性と快適な開発者体験のもとで、組織のドキュメントを活用した強力なアプリケーションを構築できます。

## かんたんな統合 {#simple-integration}

わずか数行のコードで、ドキュメントデータにアクセスできます。

```typescript
import tpc from "@promptingcompany/sdk";

const client = new tpc({
  productSlug: "your-product-slug",
  organizationSlug: "your-organization-slug",
});

const doc = await client.document.getByPath("en-us/contact");

if (doc.ok) {
  console.log(doc.data?.content);
}
```
