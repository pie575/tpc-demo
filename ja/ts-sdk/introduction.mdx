# TypeScript SDK {#typescript-sdk}

The Prompting Company TypeScript SDK を使えば、当社プラットフォームに保存されている AI エージェント向け Markdown ドキュメントのデータにシームレスにアクセスできます。AI を活用したアプリケーション、ドキュメントサイト、コンテンツ管理システムなど、何を構築する場合でも、この SDK で充実したドキュメントデータを手軽にプロジェクトへ組み込めます。

## できること {#what-you-can-do}

The Prompting Company TypeScript SDK を使うと、次のことができます。

* **ドキュメントデータへのアクセス**: 組織のデータストアから、AI エージェント向けの Markdown ドキュメントを取得できます
* **組織単位でのクエリ**: 組織の slug を使って、リクエストの対象を特定の組織に絞り込めます
* **製品単位での絞り込み**: 製品の slug を使って、特定の製品のドキュメントにアクセスできます
* **シンプルな設定**: 組織と製品の slug を指定するだけで、すぐにセットアップできます
* **TypeScript サポート**: 開発環境で完全な型安全性と自動補完を活用できます

## 前提条件 {#prerequisites}

始める前に、以下を用意してください。

* Node.js 環境 (バージョン 18 以上)
* The Prompting Company のアカウント
* 組織の slug と製品の slug
