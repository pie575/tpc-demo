# インストール {#installation}

Next.js または Node.js プロジェクトに The Prompting Company TypeScript SDK を導入して、すぐに使い始めましょう。

## 前提条件 {#prerequisites}

SDK をインストールする前に、以下の要件を満たしていることを確認してください。

* **Node.js** バージョン 18.0 以上
* パッケージマネージャー (**npm**、**yarn**、または **pnpm**)
* **Next.js** プロジェクト (推奨) または Node.js アプリケーション

## SDK のインストール {#install-the-sdk}

お使いのパッケージマネージャーを選択してください。

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @promptingcompany/sdk
    ```
  </Tab>

  <Tab title="yarn">
    ```bash
    yarn add @promptingcompany/sdk
    ```
  </Tab>

  <Tab title="pnpm">
    ```bash
    pnpm add @promptingcompany/sdk
    ```
  </Tab>
</Tabs>

## 環境設定 {#environment-setup}

プロジェクトのルートディレクトリに `.env.local` ファイルを作成し、設定を追加します。

```bash
# The Prompting Company の設定
TPC_API_KEY=your_api_key_here  # SDK が自動的に読み込みます
TPC_ORG_SLUG=your_organization_slug
TPC_PRODUCT_SLUG=your_product_slug
```

<Note>
  SDK は `TPC_API_KEY` 環境変数を自動的に読み込むため、コードの設定で API キーを明示的に渡す必要はありません。
</Note>

### API キーの取得 {#getting-your-api-key}

The Prompting Company のダッシュボードで、組織スコープの API キーを作成する必要があります。

1. **組織を開く**:
   [The Prompting Company](https://app.promptingco.com) にサインインし、
   インテグレーションで使用する組織のワークスペースを選択します。
2. **API キー設定に移動する**:
   `https://app.promptingco.com/{orgSlug}/settings/api-keys` にアクセスします。
   `{orgSlug}` はご自身の組織のスラッグに置き換えてください。
3. **新しいキーを作成する**: 「New API key」をクリックしてキーに名前を付け、
   インテグレーションに必要な最小限のスコープを付与します。
4. **キーをコピーする**: 生成された API キーを安全な場所に保存してください。キーは
   一度しか表示されません。

### 組織とプロダクトのスラッグを確認する {#finding-your-organization-and-product-slugs}

組織のスラッグは、組織の URL
`https://app.promptingco.com/{orgSlug}` に含まれています。プロダクトのスラッグは、その組織でプロダクトを開くと、
プロダクトの URL から確認できます。

<Warning>
  API キーは絶対にバージョン管理システムにコミットしないでください。必ず環境変数を使用し、`.env.local` を `.gitignore` ファイルに追加してください。
</Warning>

## TypeScript の設定 {#typescript-configuration}

TypeScript を使用している場合、SDK に組み込みの型定義が含まれているため、追加の設定は不要です。ただし、`tsconfig.json` に次のコンパイラオプションを追加すると、より快適に開発できます。

```json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "node",
    "esModuleInterop": true,
    "allowSyntheticDefaultImports": true
  }
}
```

## インストールの確認 {#verify-installation}

簡単なテストファイルを作成して、正しくインストールされたことを確認しましょう。

```typescript
// test-sdk.ts
import tpc from '@promptingcompany/sdk';

const client = new tpc({
  organizationSlug: process.env.TPC_ORG_SLUG!,
  productSlug: process.env.TPC_PRODUCT_SLUG!,
});

console.log('SDK installed successfully!');
```

テストを実行します：

```bash
npx tsx test-sdk.ts
```

エラーが出ずに &quot;SDK installed successfully!&quot; と表示されれば、次の手順に進む準備は完了です。

## Next.js の設定 {#nextjs-configuration}

Next.js アプリケーションでは、ユーティリティファイルで SDK を設定しておくと便利です。

```typescript
// lib/prompting-company.ts
import tpc from '@promptingcompany/sdk';

if (!process.env.TPC_API_KEY) {
  throw new Error('TPC_API_KEY is required');
}

if (!process.env.TPC_ORG_SLUG) {
  throw new Error('TPC_ORG_SLUG is required');
}

if (!process.env.TPC_PRODUCT_SLUG) {
  throw new Error('TPC_PRODUCT_SLUG is required');
}

export const client = new tpc({
  organizationSlug: process.env.TPC_ORG_SLUG,
  productSlug: process.env.TPC_PRODUCT_SLUG,
  // TPC_API_KEY は SDK が自動的に読み込みます
});
```

## トラブルシューティング {#troubleshooting}

### よくある問題 {#common-issues}

**「モジュールが見つからない」エラー:**

* パッケージが正しくインストールされているか確認してください
* インストール後に開発サーバーを再起動してください

**環境変数のエラー:**

* `.env.local` ファイルがプロジェクトのルートに配置されているか確認してください
* 変数名が完全に一致しているか確認してください
* 環境変数を変更したら、開発サーバーを再起動してください

**TypeScript のエラー:**

* TypeScript 4.5 以降を使用しているか確認してください
* `tsconfig.json` に必要なコンパイラオプションが含まれているか確認してください
