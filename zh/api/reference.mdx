# API 参考 {#api-reference}

以下端点参考由实时 OpenAPI 文档自动生成：

```text
https://docs.promptingcompany.com/api-reference/openapi.json
```

Mintlify 会将生成的端点页面写入 `api/reference` 目录，因此请求 schema、响应 schema、Playground 示例和客户端代码片段都会自动与应用的路由元数据保持同步。

这份生成的规范也可以直接从应用中获取：

```text
https://app.promptingco.com/api/v1/openapi.json
```

如果你在本地运行文档，并且需要用本地客户端应用进行测试，请将 OpenAPI 源指向：

```text
http://localhost:3000/api/v1/openapi.json
```
