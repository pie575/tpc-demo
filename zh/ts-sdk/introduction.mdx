# TypeScript SDK {#typescript-sdk}

The Prompting Company TypeScript SDK 让开发者能够无缝访问存储在我们平台上的面向 AI 智能体的 Markdown 文档数据。无论您是在构建 AI 驱动的应用、文档站点还是内容管理系统，借助我们的 SDK，您都能轻松将丰富的文档数据集成到自己的项目中。

## 功能概览 {#what-you-can-do}

借助 The Prompting Company TypeScript SDK，你可以：

* **访问文档数据**：从组织的数据存储中获取面向 AI 智能体的 Markdown 文档
* **按组织查询**：通过组织 slug 将请求范围限定到指定组织
* **按产品筛选**：通过产品 slug 访问指定产品的文档
* **配置简单**：只需提供组织 slug 和产品 slug 即可完成设置
* **TypeScript 支持**：在开发环境中获得完整的类型安全和自动补全

## 前提条件 {#prerequisites}

开始之前，请确保你已具备：

* Node.js 环境 (18 或更高版本)
* The Prompting Company 账户
* 你的组织 slug 和产品 slug
