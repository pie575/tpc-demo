# 安装 {#installation}

在你的 Next.js 或 Node.js 项目中快速上手 The Prompting Company TypeScript SDK。

## 前提条件 {#prerequisites}

安装 SDK 之前，请确保满足以下条件：

* **Node.js** 18.0 或更高版本
* **npm**、**yarn** 或 **pnpm** 包管理器
* 一个 **Next.js** 项目 (推荐) 或 Node.js 应用

## 安装 SDK {#install-the-sdk}

选择你常用的包管理器：

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @promptingcompany/sdk
    ```
  </Tab>

  <Tab title="yarn">
    ```bash
    yarn add @promptingcompany/sdk
    ```
  </Tab>

  <Tab title="pnpm">
    ```bash
    pnpm add @promptingcompany/sdk
    ```
  </Tab>
</Tabs>

## 环境配置 {#environment-setup}

在项目根目录下创建 `.env.local` 文件，并添加你的配置：

```bash
# The Prompting Company 配置
TPC_API_KEY=your_api_key_here  # SDK 会自动读取
TPC_ORG_SLUG=your_organization_slug
TPC_PRODUCT_SLUG=your_product_slug
```

<Note>
  SDK 会自动读取 `TPC_API_KEY` 环境变量，因此无需在代码配置中显式传入。
</Note>

### 获取 API 密钥 {#getting-your-api-key}

你需要在 The Prompting Company
控制台中创建一个组织级 API 密钥：

1. **打开你的组织**：登录
   [The Prompting Company](https://app.promptingco.com)，然后选择
   要用于此集成的组织工作区。
2. **前往 API 密钥设置**：访问
   `https://app.promptingco.com/{orgSlug}/settings/api-keys`，并将
   `{orgSlug}` 替换为你的组织 slug。
3. **创建新密钥**：点击“New API key”，为密钥命名，并仅授予集成所需的最小
   权限范围。
4. **复制密钥**：妥善保存生成的 API 密钥。该密钥仅会显示
   一次。

### 查找组织和产品的 slug {#finding-your-organization-and-product-slugs}

组织 slug 是组织 URL 的一部分：
`https://app.promptingco.com/{orgSlug}`。在该组织中打开某个产品后，即可从
产品 URL 中找到产品 slug。

<Warning>
  切勿将 API 密钥提交到版本控制系统。请始终使用环境变量，并将 `.env.local` 添加到 `.gitignore` 文件中。
</Warning>

## TypeScript 配置 {#typescript-configuration}

如果你使用 TypeScript，SDK 已内置类型定义，无需额外配置。不过，你也可以在 `tsconfig.json` 中添加以下编译器选项，以获得更好的开发体验：

```json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "node",
    "esModuleInterop": true,
    "allowSyntheticDefaultImports": true
  }
}
```

## 验证安装 {#verify-installation}

创建一个简单的测试文件，验证安装是否成功：

```typescript
// test-sdk.ts
import tpc from '@promptingcompany/sdk';

const client = new tpc({
  organizationSlug: process.env.TPC_ORG_SLUG!,
  productSlug: process.env.TPC_PRODUCT_SLUG!,
});

console.log('SDK installed successfully!');
```

运行测试：

```bash
npx tsx test-sdk.ts
```

如果看到输出 &quot;SDK installed successfully!&quot; 且没有报错，即可继续下一步。

## Next.js 配置 {#nextjs-configuration}

对于 Next.js 应用，可以在工具文件中配置 SDK：

```typescript
// lib/prompting-company.ts
import tpc from '@promptingcompany/sdk';

if (!process.env.TPC_API_KEY) {
  throw new Error('TPC_API_KEY is required');
}

if (!process.env.TPC_ORG_SLUG) {
  throw new Error('TPC_ORG_SLUG is required');
}

if (!process.env.TPC_PRODUCT_SLUG) {
  throw new Error('TPC_PRODUCT_SLUG is required');
}

export const client = new tpc({
  organizationSlug: process.env.TPC_ORG_SLUG,
  productSlug: process.env.TPC_PRODUCT_SLUG,
  // SDK 会自动读取 TPC_API_KEY
});
```

## 故障排除 {#troubleshooting}

### 常见问题 {#common-issues}

**找不到模块 (Module not found) 错误：**

* 确认已正确安装该软件包
* 安装完成后重启开发服务器

**环境变量错误：**

* 确认 `.env.local` 文件位于项目根目录
* 检查变量名是否完全匹配
* 修改环境变量后重启开发服务器

**TypeScript 错误：**

* 确保使用的是 TypeScript 4.5 或更高版本
* 确认 `tsconfig.json` 中已包含必要的编译器选项
