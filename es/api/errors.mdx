# Errores {#errors}

Los endpoints JSON de The Prompting Company devuelven un envoltorio `ApiResult<T>` tanto si la solicitud se completa correctamente como si falla.

## Estructura del resultado {#result-shape}

```ts
type ApiSuccess<T> = {
  ok: true;
  data: T;
};

type ApiError = {
  ok: false;
  code: ApiErrorCode;
  message: string;
  details?: unknown;
};

type ApiResult<T> = ApiSuccess<T> | ApiError;
```

Comprueba `ok` antes de leer `data`:

```ts
const result = await response.json();

if (!result.ok) {
  console.error(result.code, result.message, result.details);
  return;
}

console.log(result.data);
```

## Mensajes comunes {#common-messages}

| Mensaje                   | Significado                                                         |
| ------------------------- | ------------------------------------------------------------------- |
| `authentication required` | No se encontró ninguna sesión válida, token bearer ni clave de API. |
| `invalid api key`         | No se pudo verificar el valor de `x-api-key`.                       |
| `public_api_only`         | Una clave de API intentó llamar a una ruta interna.                 |
| `auth_method_not_allowed` | El endpoint no acepta el tipo de credencial que usaste.             |
| `insufficient_scope`      | A tu token bearer o clave de API le falta un scope requerido.       |
| `rate_limited`            | Superaste el límite de solicitudes del bucket actual.               |

## ID de solicitud {#request-ids}

Todas las respuestas del wrapper incluyen:

```text
x-request-id: 6efaa25e-3ef6-4a34-91c1-7ff3e0fd4cc8
```

También puedes enviar tu propio `x-request-id` si solo contiene letras, números, `_`, `.`, `-` o `:` y no supera los 128 caracteres. TPC sustituye los valores no seguros por un ID nuevo.

Si necesitas ayuda para rastrear una solicitud fallida, comparte el ID de solicitud con el equipo de soporte.
