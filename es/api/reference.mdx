# Referencia de la API {#api-reference}

La referencia de los endpoints se genera a partir del documento OpenAPI publicado:

```text
https://docs.promptingcompany.com/api-reference/openapi.json
```

Mintlify genera las páginas de endpoints en `api/reference`, de modo que los esquemas de solicitud y de respuesta, los ejemplos del playground y los fragmentos de código de cliente se mantienen sincronizados automáticamente con los metadatos de las rutas de la aplicación.

La misma especificación generada también está disponible desde la aplicación:

```text
https://app.promptingco.com/api/v1/openapi.json
```

Si ejecutas la documentación en local y necesitas hacer pruebas con una aplicación cliente local, apunta la fuente de OpenAPI a:

```text
http://localhost:3000/api/v1/openapi.json
```
