# Páginas del sitio {#site-pages}

<Warning>
  Los endpoints `/api/v1/site/pages` están obsoletos y se eliminarán en una versión futura. En su lugar, usa la API unificada del ciclo de vida del contenido: `GET/POST /api/v1/content`, `GET/PUT/DELETE /api/v1/content/{id}`, además de `POST /api/v1/content/generate` y los endpoints de revisión (`/api/v1/content/{draftId}/review`, `/revision`, `/publish`, `/revert`). Consulta los esquemas en la referencia de la API. Las páginas creadas pasan a la cola de revisión y solo se publican una vez aprobadas.
</Warning>

Las páginas del sitio son registros de contenido con ámbito de producto que incluyen una ruta, un título, un estado, un cuerpo de contenido opcional, metadatos y dominios asociados. Úsalas cuando tu fuente de referencia sea un CMS, un sitio de documentación o una carpeta de archivos Markdown.

## Listar páginas {#list-pages}

Necesitas el permiso `content:read`.

```bash
curl "https://app.promptingco.com/api/v1/site/pages?productId=$TPC_PRODUCT_ID&page=1&pageSize=25" \
  -H "x-api-key: $TPC_API_KEY"
```

Filtra por búsqueda, estado, ruta y existencia de contenido:

```bash
curl "https://app.promptingco.com/api/v1/site/pages?productId=$TPC_PRODUCT_ID&query=pricing&status=published&pathPrefix=docs/&hasContent=true" \
  -H "x-api-key: $TPC_API_KEY"
```

## Crear páginas {#create-pages}

Necesitas el permiso `content:write`.

```bash
curl "https://app.promptingco.com/api/v1/site/pages" \
  -X POST \
  -H "content-type: application/json" \
  -H "x-api-key: $TPC_API_KEY" \
  -H "Idempotency-Key: page-create-docs-install" \
  --data '{
    "productId": "'"$TPC_PRODUCT_ID"'",
    "pages": [
      {
        "slug": "docs/install",
        "title": "Install",
        "content": "# Install\n\nInstall instructions."
      }
    ]
  }'
```

Puedes crear hasta 25 páginas por solicitud.

## Actualizar páginas {#update-pages}

Envía solo los campos que quieras cambiar:

```bash
curl "https://app.promptingco.com/api/v1/site/pages" \
  -X PATCH \
  -H "content-type: application/json" \
  -H "x-api-key: $TPC_API_KEY" \
  -H "Idempotency-Key: page-update-page-123" \
  --data '{
    "productId": "'"$TPC_PRODUCT_ID"'",
    "pages": [
      {
        "id": "page_123",
        "title": "Install The Prompting Company",
        "status": "published"
      }
    ]
  }'
```

## Eliminar páginas {#delete-pages}

Las eliminaciones son lógicas (*soft deletes*). Las páginas eliminadas dejan de aparecer en los resultados habituales de las listas, pero siguen disponibles para los sistemas internos de retención y auditoría.

```bash
curl "https://app.promptingco.com/api/v1/site/pages" \
  -X DELETE \
  -H "content-type: application/json" \
  -H "x-api-key: $TPC_API_KEY" \
  -H "Idempotency-Key: page-delete-page-123" \
  --data '{
    "productId": "'"$TPC_PRODUCT_ID"'",
    "pageIds": ["page_123"]
  }'
```

Puedes eliminar hasta 50 páginas por solicitud.

## Ejemplo práctico: sincronizar archivos Markdown {#worked-example-sync-markdown-files}

```ts
import { readFile, readdir } from "node:fs/promises";
import { join, relative } from "node:path";

async function syncMarkdownFolder(root: string, productId: string, apiKey: string) {
  const names = await readdir(root);
  const pages = [];

  for (const name of names) {
    if (!name.endsWith(".md")) continue;

    const path = join(root, name);
    const content = await readFile(path, "utf8");
    const slug = relative(root, path).replace(/\.md$/, "");

    pages.push({
      slug,
      title: slug.replace(/-/g, " "),
      content,
    });
  }

  const results = [];

  for (let index = 0; index < pages.length; index += 25) {
    const batch = pages.slice(index, index + 25);
    const response = await fetch("https://app.promptingco.com/api/v1/site/pages", {
      method: "POST",
      headers: {
        "content-type": "application/json",
        "x-api-key": apiKey,
        "Idempotency-Key": `markdown-sync-${index}-${Date.now()}`,
      },
      body: JSON.stringify({ productId, pages: batch }),
    });

    results.push(await response.json());
  }

  return results;
}
```
