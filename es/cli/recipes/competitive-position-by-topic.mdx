# Posición competitiva por temas {#competitive-position-across-topics}

El widget Industry rankings del dashboard muestra los competidores más mencionados en todas las conversaciones que monitorizas. A veces necesitas una vista más detallada: en cada tema que monitorizas, ¿en qué posición estás realmente?

Esta receta usa [`tpc analytics sov`](/es/cli/commands/analytics) para responder a esa pregunta con un solo script, sin tener que hacer clic en el dashboard.

## Requisitos previos {#prerequisites}

* La CLI instalada y autenticada. Consulta [Instalación](/es/cli/installation) y [Autenticación](/es/cli/authentication).
* `--scope <org-slug>/<product-slug>` para el producto que quieres revisar.
* [`jq`](https://jqlang.org) instalado en tu equipo.

## El script {#the-script}

Cada tema requiere su propia consulta de ranking, así que el script las ejecuta de forma simultánea en lugar de una tras otra. Cada resultado se guarda en un archivo temporal para que la salida en paralelo no se entremezcle y, después, se muestra en el orden original de los temas.

```bash
#!/usr/bin/env bash
set -euo pipefail

SCOPE="${SCOPE:?set SCOPE to <org-slug>/<product-slug>}"
ORG="${SCOPE%%/*}"
SLUG="${SCOPE##*/}"
YOUR_PRODUCT=$(tpc --format json product list --scope "$ORG" \
  | jq -r --arg slug "$SLUG" '.[] | select(.slug == $slug) | .name')
if [ -z "$YOUR_PRODUCT" ]; then
  echo "product $SLUG was not found in org $ORG" >&2
  exit 1
fi

tmpdir=$(mktemp -d)
trap 'rm -rf "$tmpdir"' EXIT

check_topic() {
  local topic_id="$1" topic="$2"
  local you
  you=$(tpc analytics sov --scope "$SCOPE" --by competitor --topic "$topic_id" --top 100 --json \
    | jq -r --arg name "$YOUR_PRODUCT" '.[] | select(.label == $name) | "\(.rank)\t\(.sov)"')
  if [ -n "$you" ]; then
    local rank sov
    rank=$(echo "$you" | cut -f1)
    sov=$(echo "$you" | cut -f2)
    printf "%-14s rank #%-4s sov %s%%\n" "$topic" "$rank" "$sov"
  else
    printf "%-14s not in top 100\n" "$topic"
  fi
}

topic_ids=()
while IFS=$'\t' read -r topic_id topic; do
  topic_ids+=("$topic_id")
  check_topic "$topic_id" "$topic" > "$tmpdir/$topic_id" &
done < <(tpc analytics sov --scope "$SCOPE" --by topic --json | jq -r '.[] | [.key, .label] | @tsv')

wait

for topic_id in "${topic_ids[@]}"; do
  cat "$tmpdir/$topic_id"
done
```

Ejecútalo:

```bash
chmod +x competitive-position.sh
./competitive-position.sh
```

Ejemplo de salida:

```text
comparison     rank #1    sov 58.8%
feature        rank #2    sov 42.4%
use-case       rank #3    sov 36.0%
budget         rank #2    sov 34.2%
industry       rank #22   sov 18.0%
```

## Cómo funciona {#how-it-works}

1. `$SCOPE` es `<org-slug>/<product-slug>`. El script obtiene la organización del primer segmento (`ORG="${SCOPE%%/*}"`) y el slug del producto del segundo (`SLUG="${SCOPE##*/}"`), enumera los productos de esa organización y usa el nombre visible del producto coincidente, que es el que las filas del ranking usan como `label`.
2. `tpc analytics sov --scope "$SCOPE" --by topic` enumera todos los temas que sigues, con el ID (`key`) y el nombre (`label`) de cada uno.
3. Para cada tema, una llamada a `check_topic` en segundo plano ejecuta `tpc analytics sov --scope "$SCOPE" --by competitor --topic <topicId>`. Es la misma vista de ranking que muestra el widget Industry rankings del dashboard, pero limitada a un solo tema en lugar de a todos. Todos los temas se consultan de forma simultánea, sin tener que esperar a que termine cada uno.
4. `jq` selecciona la fila que coincide con el nombre visible de tu producto y escribe su posición y su share of voice en el archivo temporal de ese tema.
5. `wait` se bloquea hasta que terminan todas las consultas en segundo plano y, a continuación, los resultados se imprimen en el orden original de los temas (no en el orden en que finalizaron).

<Note>
  La mejora de velocidad es mayor cuantos más temas sigas. Con pocos temas, la mayor parte del tiempo real se va en la sobrecarga de cada invocación (autenticación y resolución de la organización), por lo que paralelizar ahorra menos de lo que cabría esperar. Con decenas de temas, ejecutarlos de forma simultánea en lugar de secuencial marca la diferencia entre minutos y segundos.
</Note>

<Note>
  `--top 100` es el tamaño de página máximo que permite el comando fijo. Si un tema tiene más de 100 competidores seguidos y no apareces, usa `tpc analytics explore --scope "$SCOPE" --metric sov --by competitor --topic <topicId> --page 2` en lugar de dar por hecho que no figuras en el ranking.
</Note>

## Variaciones {#variations}

¿Solo quieres el ranking general, sin desglose por tema?

```bash
tpc analytics sov --scope <org-slug>/<product-slug> --by competitor --last 30d
```

¿Prefieres el JSON sin procesar para un dashboard o un resumen de Slack en lugar de una tabla con formato? Quita las líneas `printf` y canaliza directamente la salida de `jq`. Todos los comandos de esta receta admiten `--json`.

¿Solo te interesan un par de temas? Sáltate el paso de listar los temas y escribe directamente en el código los ID de los temas que ya conoces:

```bash
tpc analytics sov --scope "$SCOPE" --by competitor --topic <topicId>
```

## Mostrar los competidores cercanos a tu posición {#show-competitors-around-your-rank}

Conocer tu posición y tu share of voice en un tema es útil, pero no te dice contra quién compites realmente en esa posición concreta. Este script toma un tema y muestra los competidores situados justo por encima y por debajo de ti, reutilizando exactamente la misma respuesta de `tpc analytics sov --by competitor --topic` que el script principal anterior. La posición de cada competidor ya viene incluida en esa única llamada, así que no hace falta ninguna solicitud adicional a la API.

```bash
#!/usr/bin/env bash
set -euo pipefail

TOPIC_ID="$1"
WINDOW="${2:-2}"

SCOPE="${SCOPE:?set SCOPE to <org-slug>/<product-slug>}"
ORG="${SCOPE%%/*}"
SLUG="${SCOPE##*/}"
YOUR_PRODUCT=$(tpc --format json product list --scope "$ORG" \
  | jq -r --arg slug "$SLUG" '.[] | select(.slug == $slug) | .name')
if [ -z "$YOUR_PRODUCT" ]; then
  echo "product $SLUG was not found in org $ORG" >&2
  exit 1
fi

rows=$(tpc analytics sov --scope "$SCOPE" --by competitor --topic "$TOPIC_ID" --top 100 --json \
  | jq -r --arg name "$YOUR_PRODUCT" --argjson window "$WINDOW" '
      . as $rows
      | ($rows | map(.label) | index($name)) as $idx
      | if $idx == null then empty else
          $rows[(if $idx - $window < 0 then 0 else $idx - $window end):($idx + $window + 1)][]
          | [.rank, .label, .sov, (if .label == $name then "you" else "" end)] | @tsv
        end
    ')

if [ -z "$rows" ]; then
  echo "$YOUR_PRODUCT is not in the top 100 for this topic"
  exit 0
fi

echo "$rows" | while IFS=$'\t' read -r rank label sov marker; do
  if [ "$marker" = "you" ]; then
    printf "%-4s %-20s %s%%  <-- you\n" "$rank" "$label" "$sov"
  else
    printf "%-4s %-20s %s%%\n" "$rank" "$label" "$sov"
  fi
done
```

Ejecútalo con un ID de tema (puedes obtenerlo con `tpc analytics sov --scope <org-slug>/<product-slug> --by topic --json` o en el paso del script anterior que lista los temas):

```bash
chmod +x competitors-around-rank.sh
./competitors-around-rank.sh a8bbcb6f-1ee3-462b-98f1-abe8e05e5437
```

Ejemplo de salida:

```text
19   MongoDB              21.15%
20   Cassandra            19.23%
21   Planetscale          19.23%  <-- you
22   AlloyDB              17.31%
23   ClickHouse           17.31%
```

Pasa un segundo argumento para ampliar o reducir la ventana (por defecto, 2 filas a cada lado):

```bash
./competitors-around-rank.sh a8bbcb6f-1ee3-462b-98f1-abe8e05e5437 5
```

<Note>
  Si ocupas el puesto n.º 1 (o estás cerca del final de la lista monitorizada) en un tema, la ventana simplemente se limita a las filas disponibles en esa dirección. Verás menos competidores por ese lado, pero no se producirá ningún error.
</Note>

## Todos los temas, con los competidores cercanos a tu posición {#all-topics-with-competitors-around-your-rank}

Combina los dos scripts anteriores: recorre todos los temas de forma concurrente (como [el primer script](#the-script)), pero, en lugar de mostrar solo tu propia fila, muestra en cada uno la ventana de competidores cercanos a tu posición (como el anterior). Conserva la misma estructura de consultas en paralelo, con trabajos en segundo plano que escriben en archivos temporales por tema, que después se reproducen en el orden original, pero incluye más filas por tema.

```bash
#!/usr/bin/env bash
set -euo pipefail

WINDOW="${1:-2}"

SCOPE="${SCOPE:?set SCOPE to <org-slug>/<product-slug>}"
ORG="${SCOPE%%/*}"
SLUG="${SCOPE##*/}"
YOUR_PRODUCT=$(tpc --format json product list --scope "$ORG" \
  | jq -r --arg slug "$SLUG" '.[] | select(.slug == $slug) | .name')
if [ -z "$YOUR_PRODUCT" ]; then
  echo "product $SLUG was not found in org $ORG" >&2
  exit 1
fi

tmpdir=$(mktemp -d)
trap 'rm -rf "$tmpdir"' EXIT

check_topic() {
  local topic_id="$1" topic="$2"
  local rows
  rows=$(tpc analytics sov --scope "$SCOPE" --by competitor --topic "$topic_id" --top 100 --json \
    | jq -r --arg name "$YOUR_PRODUCT" --argjson window "$WINDOW" '
        . as $rows
        | ($rows | map(.label) | index($name)) as $idx
        | if $idx == null then empty else

            | [.rank, .label, .sov, (if .label == $name then "you" else "" end)] | @tsv
          end
      ')

  echo "$topic"
  if [ -z "$rows" ]; then
    printf "  %s not in top 100\n" "$YOUR_PRODUCT"
  else
    echo "$rows" | while IFS=$'\t' read -r rank label sov marker; do
      if [ "$marker" = "you" ]; then
        printf "  %-4s %-20s %s%%  <-- you\n" "$rank" "$label" "$sov"

      fi
    done
  fi
  echo
}

topic_ids=()
while IFS=$'\t' read -r topic_id topic; do

```
