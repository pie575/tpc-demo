Tu base de conocimiento es el repositorio compartido de datos y directrices sobre un producto. Piensa en ella como una biblioteca privada y exclusiva de cada producto que proporciona a The Prompting Company el contexto que necesita para responder y redactar con precisión.

Puede incluir:

* Descripciones, funciones y elementos diferenciadores del producto
* Información sobre la audiencia, los clientes y los casos de uso
* Posicionamiento, competidores y afirmaciones aprobadas
* Directrices de redacción y reglas de contenido
* Material de referencia importado de tu sitio web, tu documentación y otras páginas de confianza

Cada producto tiene su propia base de conocimiento, de modo que su contexto se mantiene separado del de tus demás productos.

## Cómo se usa la base de conocimiento {#how-the-knowledge-base-is-used}

The Prompting Company usa tu base de conocimiento como fuente de referencia para el trabajo específico de cada producto en toda la plataforma:

* **Sugerencias y refinamiento de prompts:** El contexto del producto ayuda a generar preguntas relevantes que tu audiencia podría hacer a los asistentes de IA.
* **Generación de contenido:** Los datos, el posicionamiento y las directrices de redacción ayudan a que el contenido generado sea preciso y coherente con tu producto.
* **Asistente del espacio de trabajo:** El asistente busca en los archivos relevantes de la base de conocimiento antes de realizar tareas que dependen de datos del producto.
* **Precisión de los datos:** Las afirmaciones sobre el producto se pueden contrastar con la base de conocimiento y con las fuentes en las que confías.

La base de conocimiento sirve de apoyo a estos flujos de trabajo, pero no publica sus archivos como contenido de cara al cliente.

## Añadir y mantener el conocimiento {#add-and-maintain-knowledge}

Durante la configuración del producto, confirma las URL del sitio web y de la documentación que servirán de base para tu base de conocimiento. Para añadir más información más adelante:

1. Selecciona tu producto y abre **Knowledge** en la barra lateral.
2. En **Overview**, selecciona **Add link** para importar una página de confianza.
3. Pide al asistente del espacio de trabajo, en lenguaje natural, que añada o corrija datos, posicionamiento o pautas.
4. Abre **Files** para revisar la información y las reglas de contenido almacenadas para el producto.
5. Revisa los cambios propuestos antes de que pasen a formar parte de la base de conocimiento.

Mantén la base de conocimiento al día cada vez que cambien las funcionalidades, los precios, el posicionamiento o las afirmaciones aprobadas del producto. Cuanto más completo y preciso sea el material de origen, mejor contexto tendrá la plataforma para futuros prompts, contenido y análisis.

<Tip>
  Añade fuentes autorizadas que describan el producto directamente. Evita páginas con afirmaciones desactualizadas o con información que corresponda a otro producto.
</Tip>
