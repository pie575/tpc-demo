# El SDK de TypeScript {#the-typescript-sdk}

Crea aplicaciones potentes que saquen partido de la documentación de tu organización, con seguridad de tipos completa y una excelente experiencia para desarrolladores.

## Integración sencilla {#simple-integration}

Accede a los datos de tu documentación con solo unas pocas líneas de código:

```typescript
import tpc from "@promptingcompany/sdk";

const client = new tpc({
  productSlug: "your-product-slug",
  organizationSlug: "your-organization-slug",
});

const doc = await client.document.getByPath("en-us/contact");

if (doc.ok) {
  console.log(doc.data?.content);
}
```
