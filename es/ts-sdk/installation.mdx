# Instalación {#installation}

Empieza a usar el SDK de TypeScript de The Prompting Company en tu proyecto de Next.js o Node.js.

## Requisitos previos {#prerequisites}

Antes de instalar el SDK, asegúrate de tener:

* **Node.js** versión 18.0 o superior
* Un gestor de paquetes: **npm**, **yarn** o **pnpm**
* Un proyecto de **Next.js** (recomendado) o una aplicación de Node.js

## Instala el SDK {#install-the-sdk}

Elige el gestor de paquetes que prefieras:

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @promptingcompany/sdk
    ```
  </Tab>

  <Tab title="yarn">
    ```bash
    yarn add @promptingcompany/sdk
    ```
  </Tab>

  <Tab title="pnpm">
    ```bash
    pnpm add @promptingcompany/sdk
    ```
  </Tab>
</Tabs>

## Configuración del entorno {#environment-setup}

Crea un archivo `.env.local` en la raíz de tu proyecto y añade tu configuración:

```bash
# Configuración de The Prompting Company
TPC_API_KEY=your_api_key_here  # El SDK la lee automáticamente
TPC_ORG_SLUG=your_organization_slug
TPC_PRODUCT_SLUG=your_product_slug
```

<Note>
  El SDK lee automáticamente la variable de entorno `TPC_API_KEY`, así que no hace falta que la pases explícitamente en la configuración de tu código.
</Note>

### Cómo obtener tu clave de API {#getting-your-api-key}

Deberás crear una clave de API con alcance de organización desde el dashboard de The Prompting Company:

1. **Abre tu organización**: inicia sesión en
   [The Prompting Company](https://app.promptingco.com) y selecciona el
   espacio de trabajo de la organización que usarás para tu integración.
2. **Ve a la configuración de claves de API**: visita
   `https://app.promptingco.com/{orgSlug}/settings/api-keys` y reemplaza
   `{orgSlug}` por el slug de tu organización.
3. **Crea una nueva clave**: haz clic en «New API key», ponle un nombre a la clave y concede solo el alcance
   mínimo que necesite tu integración.
4. **Copia la clave**: guarda la clave de API generada en un lugar seguro. Solo se mostrará
   una vez.

### Cómo encontrar los slugs de tu organización y producto {#finding-your-organization-and-product-slugs}

El slug de tu organización forma parte de la URL de la organización:
`https://app.promptingco.com/{orgSlug}`. Puedes obtener el slug de un producto en la
URL del producto tras abrirlo dentro de esa organización.

<Warning>
  Nunca subas claves de API al control de versiones. Usa siempre variables de entorno y agrega `.env.local` a tu archivo `.gitignore`.
</Warning>

## Configuración de TypeScript {#typescript-configuration}

Si usas TypeScript, el SDK ya incluye sus propias definiciones de tipos. No necesitas ninguna configuración adicional, aunque puedes mejorar tu experiencia de desarrollo si añades estas opciones del compilador a tu `tsconfig.json`:

```json
{
  "compilerOptions": {
    "strict": true,
    "moduleResolution": "node",
    "esModuleInterop": true,
    "allowSyntheticDefaultImports": true
  }
}
```

## Verificar la instalación {#verify-installation}

Crea un archivo de prueba sencillo para comprobar que la instalación funciona correctamente:

```typescript
// test-sdk.ts
import tpc from '@promptingcompany/sdk';

const client = new tpc({
  organizationSlug: process.env.TPC_ORG_SLUG!,
  productSlug: process.env.TPC_PRODUCT_SLUG!,
});

console.log('SDK installed successfully!');
```

Ejecuta la prueba:

```bash
npx tsx test-sdk.ts
```

Si ves &quot;SDK installed successfully!&quot; sin errores, ya puedes continuar.

## Configuración de Next.js {#nextjs-configuration}

En aplicaciones Next.js, quizá te convenga configurar el SDK en un archivo de utilidades:

```typescript
// lib/prompting-company.ts
import tpc from '@promptingcompany/sdk';

if (!process.env.TPC_API_KEY) {
  throw new Error('TPC_API_KEY is required');
}

if (!process.env.TPC_ORG_SLUG) {
  throw new Error('TPC_ORG_SLUG is required');
}

if (!process.env.TPC_PRODUCT_SLUG) {
  throw new Error('TPC_PRODUCT_SLUG is required');
}

export const client = new tpc({
  organizationSlug: process.env.TPC_ORG_SLUG,
  productSlug: process.env.TPC_PRODUCT_SLUG,
  // El SDK lee TPC_API_KEY automáticamente
});
```

## Solución de problemas {#troubleshooting}

### Problemas comunes {#common-issues}

**Error de módulo no encontrado:**

* Asegúrate de haber instalado el paquete correctamente
* Reinicia tu servidor de desarrollo después de la instalación

**Errores de variables de entorno:**

* Verifica que tu archivo `.env.local` esté en la raíz del proyecto
* Comprueba que los nombres de las variables coincidan exactamente
* Reinicia tu servidor de desarrollo después de modificar las variables de entorno

**Errores de TypeScript:**

* Asegúrate de usar TypeScript 4.5 o una versión posterior
* Verifica que tu `tsconfig.json` incluya las opciones del compilador necesarias
