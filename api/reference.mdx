# API reference

The endpoint reference is generated from the live OpenAPI document:

```text
https://docs.promptingcompany.com/api-reference/openapi.json
```

Mintlify writes generated endpoint pages under `api/reference`, so request schemas, response schemas, playground examples, and client snippets track the application route metadata automatically.

The same generated spec is also available from the application:

```text
https://app.promptingco.com/api/v1/openapi.json
```

If you are running docs locally and need to test against a local client app, point the OpenAPI source at:

```text
http://localhost:3000/api/v1/openapi.json
```
